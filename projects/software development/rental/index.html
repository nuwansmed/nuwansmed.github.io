    Rental Management System¶

    Overview¶

    The Rental Management System is a comprehensive web application designed to streamline and automate the management of rental equipment and machinery. It efficiently handles batch-level and unit-level inventory, providing a centralized platform for rental businesses to manage equipment records, track availability, schedule maintenance, and more. This system aims to simplify rental operations by reducing manual effort and increasing overall productivity.

    Features¶

    Inventory Management¶

    • Batch and Unit-Level Tracking: Manages equipment at both batch and unit levels. Equipment units are associated with their respective batches, making it easier to track and organize assets.
    • Automatic SKU Generation: Automatically generates SKUs based on category and machine type codes for better identification and categorization.
    • Dynamic Equipment Info Modals: Provides detailed information modals for equipment units and batches, displaying all essential attributes.
    • Editable Equipment Data: Allows authorized users to edit equipment attributes such as brand, model number, serial number, and more at both batch and unit levels.
    • Filtering and Search: Offers extensive filtering capabilities based on attributes like brand, model, category, machine type, and warehouse location.

    Equipment Lifecycle Management¶

    • Add and Remove Equipment: Provides the ability to add new equipment to existing batches, as well as edit, update, and delete equipment data as required.
    • Condition and Maintenance Tracking: Allows for tracking the condition of equipment over its lifecycle, including warranty and insurance expiration dates.
    • Supplier and Purchase Details: Maintains records of supplier details, purchase costs, invoice numbers, and other procurement information.

    Data Visualization and Reporting¶

    • Data Grids with Inline Actions: Utilizes interactive data grids that allow users to perform actions like viewing, editing, and deleting records directly from the table view.
    • Summary Views: Displays an overview of key information, such as the total number of items in each batch and a summary of batch-level details.

    Security and User Management¶

    • User Authentication and Permissions: Ensures that only authorized users can access, edit, or delete records through authentication and role-based permissions.
    • Audit Logs: Keeps track of all critical actions like equipment modifications, deletions, and additions for accountability and traceability.

    Technology Stack¶

    Frontend¶

    • React.js: Provides a dynamic and interactive user interface. Components like forms, tables, and modals are built using React for a seamless user experience.
    • Material-UI: Implements Material Design principles using MUI components for consistent styling and responsiveness. Features like DataGrid, Dialog, and Form components ensure high usability.
    • Axios: Handles asynchronous HTTP requests to the backend API for performing CRUD operations.

    Backend¶

    • Django: A robust web framework that serves as the backbone for the server-side logic. Django REST Framework (DRF) is used to create a well-structured and modular RESTful API.
    • Django REST Framework (DRF): Manages endpoints for batch-level and unit-level inventory, allowing smooth data exchange between the client and the server.
    • PostgreSQL: Acts as the primary relational database for storing equipment records, batch information, and user details. PostgreSQL’s reliability and scalability make it an ideal choice for handling extensive inventory data.

    Architecture¶

    The Rental Management System follows a modular monolithic architecture, organizing different modules by feature while maintaining a consistent codebase. The primary modules are:

    • Admin Panel: Allows admins to manage category information, warehouses, machine types, and other essential data.
    • Inventory Management Module: Handles all batch-level and unit-level CRUD operations, SKU generation, filtering, and data visualization.
    • User and Permissions Module: Manages user authentication and role-based permissions.

    The system also integrates versioning of APIs to ensure backward compatibility and smooth feature enhancements over time.

    API Design and Endpoints¶

    The REST API has been designed with consistency and scalability in mind. It includes endpoints such as: - /api/inventory/v1/batches/: Handles CRUD operations for batch-level data. - /api/inventory/v1/units/: Manages unit-level operations like listing, updating, and deleting individual units. - /api/inventory/v1/units/list-all/: Provides a comprehensive view of all equipment units with batch-level context.

    Deployment and Scalability¶

    The application is containerized using Docker for consistent deployment and easy scalability. Nginx is employed as a reverse proxy, providing load balancing and SSL termination. The application is deployed on AWS EC2 instances with managed databases on RDS, ensuring high availability and fault tolerance.

    Summary¶

    The Rental Management System is a feature-rich, highly scalable, and secure platform that automates and simplifies rental equipment management. By leveraging modern frontend and backend technologies, the system provides an intuitive user experience and robust data handling capabilities. With a strong focus on flexibility, extensibility, and security, this system is an ideal solution for rental companies looking to streamline their operations and enhance productivity.
