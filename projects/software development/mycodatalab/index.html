    MycoDataLab - Data Management for Biological Research¶

    Overview¶

    MycoDataLab is a data management software designed to streamline and organize the recording of research data across different experimental processes. During my research on scab disease in guava and through collaborations with colleagues in various biological studies, I recognized the need for a cohesive system to efficiently record and visualize relationships between different experimental data points. In response, I developed MycoDataLab as a versatile solution tailored for biological research.

    The software is built with a React frontend using Semantic UI for a clean and responsive user experience, and it leverages Python Flask as the backend for API services.

    Key Technologies¶

    • Frontend: React with Semantic UI
    • Backend: Python Flask
    • Data Storage: JSON-based schema for flexibility in form definition
    • Mapping: Integrated map view for location data visualization

    Features & Modules¶

    MycoDataLab is composed of several interconnected modules, each designed to handle specific types of research data. These modules ensure that researchers can maintain clear, structured records throughout different stages of their experiments:

    1. Location Data Manager
    2. Input and manage data related to field locations where samples are collected.

    3. Visualize entered locations on an interactive map.

    4. Sample Data Manager

    5. Record details about collected samples.

    6. Select associated locations from a dynamically populated dropdown menu, ensuring consistency and ease of use.

    7. Culture Data Manager

    8. Document and track cultured samples, including conditions and outcomes.

    9. Link sample records for a comprehensive data trail.

    10. Microscopy Data Manager

    11. Record details of microscopy observations, capturing various parameters and linking them to relevant samples and cultures.

    12. Bioassay Data Manager

    13. Manage bioassay experiments and outcomes, linking assays to relevant sample and culture data for streamlined analysis.

    14. Sequencing Data Manager

    15. Record and manage sequencing data, linking records to corresponding samples or cultures to maintain traceability.

    Custom Form Definitions¶

    One of MycoDataLab's key features is its flexibility in data entry. Since different researchers and studies have unique data requirements, the software utilizes a JSON schema to define form fields. Researchers can create custom forms tailored to their specific needs, ensuring that all relevant data points are captured.

    Interconnected Data Visualization¶

    The modules within MycoDataLab are interconnected to provide a holistic view of the research data. For example: - When entering sample data, users can select a location from a dropdown menu that automatically populates based on the available entered locations. - The map view allows users to see the geographic distribution of samples, providing valuable insights into the spatial relationships between data points.

    Future Enhancements¶

    The current version of MycoDataLab focuses on core data management and inter-module connectivity. Future plans include: - Advanced data visualization options for generating graphs and reports. - Collaboration features to allow multiple researchers to work simultaneously on projects. - API integrations for connecting with external data analysis tools.

    MycoDataLab is designed to empower researchers by providing a flexible, organized, and visual approach to data management, making it easier to maintain comprehensive records and gain insights into experimental relationships.
